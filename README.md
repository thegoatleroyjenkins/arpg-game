# ARPG Game

A Godot 4 action RPG with equipment system, enemy AI, and progression.

## Features

- **Combat System** — Real-time melee combat with attack cooldowns
- **Equipment System** — Weapons, armor, and accessories with stat bonuses
- **Enemy AI** — State machine with chase/attack/retreat behaviors
- **Progression** — XP and leveling system
- **World Generation** — Random enemy and item spawning

## Download

Get the latest Windows build from [Releases](../../releases).

## Controls

- **WASD / Arrow Keys** — Move
- **Space / Click** — Attack
- **Walk over items** — Pick up/equip

## Development

Built with Godot 4.2. Requires Godot engine to run from source.

```bash
godot --path .
```
